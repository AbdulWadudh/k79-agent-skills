## Installation

```bash
bunx skills@latest add AbdulWadudh/k79-agent-skills -y
```

Default: project-local. Creates `.agents/skills/` and `skills-lock.json`; no agent selection and no per-agent mirrors. Advanced: add `-g` for `~/.agents/skills/`, or `-a <agent>` / `--agent '*'` for mirrors.

## Updating

Re-run the install command for the scope you use. `skills add` reads the latest default branch, so a separate update step is optional. For a hash-based refresh, run `bunx skills@latest update -y` (current scope) or `-g -y` / `-p -y`.
